# Arden Project CPT data model

No ACF dependency is introduced.

Core WordPress fields used now:

- `post_title`: project/case-study title.
- `post_excerpt`: archive card description.
- `post_content`: full case-study narrative.
- Featured image: archive and hero image.
- Publish date and permalink: native WordPress values.

Source fields that need a future native metabox or an approved field framework before exact production data entry:

- Category/product type.
- Fabric/material.
- Quantity/MOQ.
- Production duration.
- Print/embroidery technique.
- Size range.
- Completion status and outcome metrics.
- Project gallery.

Until that model is approved, templates must not invent these values or install ACF automatically.
