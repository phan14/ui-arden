# CF7 styling and states

The child theme stylesheet `assets/css/forms.css` owns presentation. It covers labels, controls, checkbox/radio, focus-visible, invalid/disabled states, submit controls and CF7 success/error notices, including a one-column mobile layout. Do not edit Contact Form 7 core files.

After inserting each shortcode, test keyboard tab order, visible focus, browser and CF7 validation, one real successful delivery, one simulated mail failure, disabled submit behavior and widths at 390/768/1024/1440px. If selectable-card enhancement is added, native inputs must remain operable without JavaScript.
